Frequently Asked Questions ❓

1️⃣ What Minecraft versions are supported?

ZX Spectrum! supports everything from Minecraft version 1.8.9 all the way up to 1.21.11, including the latest available version. We made sure players using older PvP-focused clients as well as players using the newest version can all connect without issues. This gives maximum flexibility and allows everyone to join regardless of their preferred version.

2️⃣ Is the server Java Edition only?

At the moment the server supports Java Edition only. However, we are actively planning to introduce Bedrock support in the future. The goal is for Java and Bedrock players to connect to the exact same server world and play together seamlessly.

3️⃣ Is PvP enabled everywhere?

Yes. PvP is enabled everywhere on the server — including spawn. There are no safe zones. The survival experience is consistent across the entire world, which means you always need to stay alert and prepared.

4️⃣ Are there any custom plugins or gameplay modifications?

We do use some plugins, but they do not significantly change the core survival experience. We have basic quality-of-life features like /home and authentication plugins such as AuthMe, along with other backend tools that help maintain stability and security. The gameplay itself remains very close to vanilla survival.

5️⃣ Does the world ever reset?

The world has never been reset and it will never be reset. There was one incident during a server migration where files were being transferred and an interruption caused some chunks to regenerate. Unfortunately, this happened because of a mistake while copying data and backups. Some houses disappeared (including mine), and about half of the transferred files were affected. However, the overall world remained intact and the server continued running normally. Since then, everything has been stable and there are no plans for any resets.

6️⃣ Is the server pay-to-win?

Absolutely not. The server is not pay-to-win in any way. In fact, pay-to-win mechanics would violate Mojang’s Terms of Service. We do have a shop, but everything offered there fully complies with Mojang's policies and does not provide unfair competitive advantages in PvP.

7️⃣ Where is the server hosted?

The server is physically self-hosted in Europe, specifically in Bratislava, Slovakia. It runs on a dedicated HP ProLiant DL380 G7 home server with 60GB of RAM, with the Minecraft server allocated exactly 17 GiB. The connection speed reaches up to 4Gb/s, ensuring extremely fast and stable performance.

8️⃣ How do you handle cheaters?

Cheaters are first warned by the staff team. If they continue, they receive a 6-hour jail punishment. If they violate the rules again (using x-ray, click teleport, fly, killaura or anything similar), they receive a 7-day ban. If it happens again after that, the ban becomes permanent. We believe this gives players enough chances to correct their behavior. Each warning also includes a suggestion to join an anarchy server if they prefer cheating.

9️⃣ Do you organize community events?

When enough players are active, yes — events are planned. We have the technical setup including scoreboard systems and infrastructure ready. While no large-scale events have been hosted yet, we fully intend to introduce competitions and organized activities in the future.

🔟 How can I contact staff or report a bug?

All players can join our Discord server to communicate directly with staff members. Alternatively, you can use the contact page available on our website to send us a message. We actively monitor both communication channels.
